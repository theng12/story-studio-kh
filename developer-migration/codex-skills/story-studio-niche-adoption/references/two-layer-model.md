# Formula + Topic Pack Model

## Formula owns

- channel promise and recurring hook
- title patterns and exclusions
- script sequence and evidence standards
- scene/thumbnail communication rules
- structural-diversity axes and duplicate threshold

## Topic Pack owns

- subjects, locations, periods, roles, industries, assets, and constraints
- supported formula IDs and exclusions
- source/research hints where appropriate

## Idea campaign pattern

For each candidate, select one value from several axes, reject invalid combinations, normalize the resulting subject/title, compare against existing and in-batch candidates, then persist only distinct ideas. Queue long campaigns as `idea_campaign` jobs and leave a resumable result manifest rather than a one-shot UI-only response.
