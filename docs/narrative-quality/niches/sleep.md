# Sleep Stories

**Resolved perspective:** Formula-selected narrator style; default first-person intimate voice, with explicit style variants allowed.

**Quality contract:** Literary, unhurried, low-stakes, and repetitive in a soothing—not robotic—way. This niche already has the strongest anti-mechanical sentence rules.

**Opening and outline:** Settle place, character, and tiny task; move gently through sensory detail; allow only warm turns; close on stillness.

**Avoid:** Hooks, cliffhangers, conflict, conspicuous plot twists, repeated pronoun chains, dramatic moralizing, and abrupt creator-language endings.
