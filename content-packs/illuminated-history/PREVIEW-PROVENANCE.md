# Illuminated History preview provenance

Twenty previews are declared by seven of this collection's eight standalone Content Packs. **None of them exists yet.** This file records why, exactly what must be run to produce them, and the prompt text prepared for each, so the render is a keyed operator's single step rather than a re-authoring pass.

The pack that declares no raster assets — `com.storystudio.topic.turning-points-and-eras` — is complete: it builds deterministically, signs, and passes `validateContentPack` under an ephemeral authoring key. The other seven are **blocked on previews only**; their documents already validate against the signed Content Pack schema, which was checked directly by building each of them once in a throwaway directory under the system temporary directory with disposable rasters in place. Those rasters were deleted and no placeholder byte was written into this repository.

## Three previews per visual style, four per recipe, one swatch per lettering style

The owner's rule, set on 2026-09-08 and applied to Royal History first, carries forward here: every Visual Style declares **three** previews rather than one, and the three are chosen so a buyer sees the style where it is easy, where it is quiet, and where it is hard.

- **hero** — the shot the style exists for, the one a cover would use.
- **scene** — a quiet wide scene with **no figure in it at all**, so a buyer can see what the look does to an empty frame.
- **hardest case** — the hardest thing the style can be asked for, chosen inside the style's own contract rather than against it.
  - Illuminated Frame Painting is a picture inside a gold border, so its hardest case is the one place the two halves collide: a head held close inside the opening with *painted* gold in the picture — a gilded chair back, a circlet on a cushion — sitting directly against the *real* burnished gold of the border, where both must still read as two different golds and the flesh must stay painterly at portrait range. That preview is named `-face` because the case is a face.
  - Dark Sepia Documentary Scene forbids close faces by name in its own contract, so its hardest case is the opposite of a portrait: a crowded interior in which a dozen small figures, all held at distance and none legible, have to be told entirely by one hearth, with the far wall genuinely dark and the mist still doing the work of depth. That preview is named `-hardest` rather than `-face`, because a face is the one thing this look must never produce.

Each Thumbnail Recipe declares four, as the Lost Voyage, Royal History, Golden Epic, Midnight Archives, Sleep Theories, Gory Cartoon History and Cartoon Animal Explainer recipes did, so that the fixed frame is shown against four different subjects and a buyer can see what actually varies between episodes. Each Lettering Style declares one swatch, at the 1024x576 figure the shipped paid lettering packs already use, because a lettering style is bought by looking at it and one correctly spelled specimen is what there is to look at.

## Why nothing was rendered in the authoring pass

`docs/VISUAL_STYLE_CONTENT_PACK_FORMAT.md` and the `story-studio-visual-style-adoption` skill both state that this control Mac verifies preview handoffs and does not perform production image generation, and that previews come only from owner-supplied original bytes or a production-preview handoff. That standing rule is lifted only by an explicit owner authorisation given in chat for one named pass, as it was for the earlier collections on 2026-09-08. No such authorisation covers this pass, so nothing was generated, nothing was substituted, and no placeholder bytes were written that would let a pack pass validation dishonestly.

## The exact command a keyed operator must run

Same route the earlier collections used: the Image Pool generator inside a running Story Studio app, in a project whose configured image product is the GenStudio text-to-image lane for `gpt-image-2`. One variant each, aspect `16:9`, `reference_images: []` (text-only, no reference asset, no image-to-image, no compositing, no post-render typography — the lettering in the recipe previews and in the two swatches is drawn by the image model, as the lettering and recipe contracts require).

```
POST /api/projects/pack-previews/image-pool/generate
Content-Type: application/json

{
  "pool_id": "pack-previews",
  "model": "gpt-image-2",
  "aspect_ratio": "16:9",
  "resolution": "2K",
  "variants": 1,
  "run_id": "illuminated-history-previews-1",
  "prompts": [ ...prompts 1-7 below, in order... ]
}
```

Then repeat the same request shape three more times, changing only the run id and the prompt list:

| Run id | Prompts | What it covers |
| --- | --- | --- |
| `illuminated-history-previews-1` | 1-7 | both Visual Styles, three previews each, plus the first lettering swatch |
| `illuminated-history-previews-2` | 8-12 | the Framed Subject with Dates recipe, four previews, plus the second lettering swatch |
| `illuminated-history-previews-3` | 13-16 | the Medallion Portrait recipe, four previews |
| `illuminated-history-previews-4` | 17-20 | the Numbered Series Card recipe, four previews |

Then poll each returned job, retain the returned PNGs outside the repository, and convert each accepted original with a whole-image resize (cover, lanczos3) plus WebP quality 90 effort 6 to the dimensions in the table — no crop beyond the sub-pixel aspect trim, no overlay, composite, or repair, falling back to lossless effort 6 for any file landing under the 20,480-byte floor, as the flat charcoal lettering swatches in Baroque Myth did. Record the original digest and byte count, the accepted digest, byte count and decode result, and the credits spent, in the table below before committing the bytes.

### Request size

No run id carries more than seven prompts, which is the ceiling this collection works to, and each run's prompt list serialises well inside the 16 KiB body cap that blocked the thirteen-prompt Midnight Archives batch on Story Studio 1.4.128 and earlier. The four runs are split so that no pack's preview set is divided across two jobs: a partially rendered recipe is worse than an unrendered one, because it invites a half-populated commit. Do not shorten, merge or reword a prompt to save bytes — the prompt text is the contract. The credits are 20 × 29 = 580 across the four runs.

## Acceptance rules specific to this collection

Original subjects only. This is a history collection, and the packs themselves permit real historical figures to be named in an episode — but **no preview in this collection depicts, names or dates any real person, treaty, war, expedition or place.** Every figure described below is an anonymous invented type in the dress of a stated century, every title is invented specimen wording chosen so that it names no actual event, and every span of years is an invented specimen span. A returned image that reproduces a recognisable individual, a real coat of arms, a real national or dynastic emblem, a real map of an identifiable country, a real currency, or a copied composition from a known painting must be rejected rather than committed.

No nudity and no bare skin beyond faces and hands appears in any prompt in this collection, and a returned image showing a bare shoulder, a bare torso, an undraped figure or a child must be rejected rather than committed. No blood, no wound, no execution, no battlefield casualty and no person in visible distress appears in any prompt, and a returned image containing any of them must be rejected rather than committed.

The six Visual Style previews must carry no word in any language: a returned image with readable lettering anywhere in it is unusable. The two lettering swatches and the twelve recipe previews are the opposite case — their lines must be spelled exactly as written, correctly tracked, unclipped at both ends, with no extra line and no ornament of any kind, and with every en dash rendered as a dash rather than as a hyphen pair or a word. In the Numbered Series Card previews the map must carry no lettering at all: a returned map with a place name, a cartouche or a legend on it must be rejected rather than committed.
