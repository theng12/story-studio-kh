# Plants

**Resolved perspective:** Third-person deadpan botany explainer.

**Quality contract:** One plant, one evolutionary/ecological constraint, one mechanism. Plants have no conventional agency.

**Opening and outline:** Start with a visible adaptation or habitat problem, then explain pollination, roots, chemistry, photosynthesis, or reproduction.

**Avoid:** Treating plants as sentient decision-makers, botanical folklore presented as science, and dark-comedy language that obscures ecology.
