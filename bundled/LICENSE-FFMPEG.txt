FFmpeg License & Attribution
============================

This application bundles pre-built FFmpeg and FFprobe binaries inside the
.app package (Contents/Resources/ffmpeg/) to provide audio and video
assembly without requiring a separate install.

Bundled version
---------------
FFmpeg 8.1
  Universal2 binary fused with `lipo` from per-arch builds:
    - arm64 (Apple Silicon): https://www.osxexperts.net/ffmpeg81arm.zip
    - x86_64 (Intel):        https://evermeet.cx/ffmpeg/ffmpeg-8.1.zip

FFprobe 8.1
  Same fusion, sources:
    - arm64:  https://www.osxexperts.net/ffprobe81arm.zip
    - x86_64: https://evermeet.cx/ffmpeg/ffprobe-8.1.zip

Bundled libraries
-----------------
The bundled FFmpeg statically links the following libraries (per
`ffmpeg -version` output of the bundled binary):
  - libx264, libx265, libvpx, libsvtav1, libaom, libvvenc, libkvazaar
    (video codecs)
  - libopus, libmp3lame, libvorbis, libtheora, libsnappy, libwebp
    (audio + image codecs)
  - libass, libfreetype, libfontconfig, libharfbuzz
    (text rendering / subtitle burn-in)
  - libvmaf, libzimg, libvidstab, libopenjpeg
    (analysis + filtering)

Each library is licensed under its own terms; see ffmpeg.org/legal.html
for the full upstream attribution and license matrix.
