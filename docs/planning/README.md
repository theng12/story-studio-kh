## When to update

Mark items `[~]` when you start, `[x]` when shipped (link the version + commit). When a whole document's items are all `[x]`, move it to [`../history/`](../history/) with a date suffix.

## When to add a file here

A new backlog earns its own file when it covers a distinct surface (e.g., "upload" vs. "video assembly") and would otherwise turn this directory's existing backlogs into ten-page documents. Otherwise keep adding to the closest existing one.
