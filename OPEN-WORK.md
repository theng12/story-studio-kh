# Open work — story-studio-kh

Open tasks and known defects for this repository only; updated in the same commit whenever work starts, changes, or closes. Shipped work lives in `CHANGELOG.md` and `docs/receipts/`.

- [ ] **The double-booking refusal guard is not built** — the publishing classification and the upload-centre route exist, and relayout already routes around days held by other episodes, but nothing refuses a direct assignment of an episode to a date that is already on YouTube or already planned through plan/apply, relayout/apply or the per-episode schedule. **Next:** add the refusal that names the clashing episode, at all three entry points, with a test that fails without it.
- [ ] **`missing_slots_4w` is computed from confirmed coverage, not from the per-date classification** — the column walks cadence slots against confirmed YouTube schedules plus outside releases (`electron/server/services/publishing-overview.ts:765-786`), while `classifyChannelDates` (`electron/server/services/channel-date-classification.ts:35`) already gives every date exactly one state — `on-youtube`, `planned`, `free` or `unknown`. So a date the app cannot see at all is counted as missing here, and the two can report different numbers for the same channel. **Next:** compute the column from the classification, or label it so the two cannot silently disagree.
- [ ] **The black-frame and silence thresholds do not match the owner's 15 s decision** — the owner chose 15 s for both. `black_min_sec` defaults to 2 (`electron/server/lib/final-video-check.ts:417`) and has no setting anywhere: `SafetyChecksSettings.vue` offers `silence_min_sec` only, and nothing in the frontend mentions black. `silence_min_sec` itself still defaults to 10 (`final-video-check.ts:421`, saved as `?? 10` at `SafetyChecksSettings.vue:90`), so a channel that never touched the field runs at the old value. **Next:** default black to 15 with the same per-channel shape as silence (adjustable, switchable off) and wire both into the settings page.
- [ ] **Uploads per day is not an adjustable setting** — the owner chose one number per channel, default 10, adjustable 1–100, feeding the spacing; today `upload_quota` is a locked, non-switchable check (`electron/server/services/safety-checks.ts:42,122`) carrying no number, and `publish_cadence` is a weekday pattern. **Next:** add the setting with that range and default, show it in the UI, and derive the spacing from it.
- [ ] **Output-affecting defaults are still read when the job renders, not when it is queued** — a model size or default that changes between enqueue and render changes what the job produces. The 1024×576 default itself is shipped on `main` (`electron/server/contracts/genstudio-image-defaults.ts:38`, `2448a6597`), but pinning the resolved values into the job's params at creation is not built. **Next:** freeze the resolved size and model defaults into the job record when it is enqueued, and prove an update between queue and render cannot change the output.
- [ ] **A non-episode key can be imported and rendered as a publishing slot** — a plain item→timestamp map takes any key, so `import:test.mp4` was counted as a December slot and inflated the plan-versus-YouTube count by one. **Next:** refuse a key that is not an episode at import, and never render one as a slot; check both with a scratch channel.
- [ ] **The resume decision never reads the scene's `.check.json`** — a picture is treated as done when the PNG exists and decodes and the plan's rendered prompt still matches (`electron/server/generators/continuity-render.ts`, the resume scope); `*.check.json` is written by the quality check and read by Scene Review only. So "PNG plus check file is done" is not what the code does. **Next:** decide which rule is authoritative and make the resume honour it, or record the divergence so nobody relies on the other reading.
- [ ] **The AI disclosure is not the line the owner chose** — the owner picked the plain sentence "Created with the help of AI tools." for every package that has none. The code instead emits per-process sentences ("The narration voice was generated with AI." / "The images were generated with AI tools.", `electron/server/lib/ai-disclosure.ts:47-56`), and the owner's sentence survives only as `LEGACY_NEUTRAL_AI_DISCLOSURE` — a string the generator treats as a *default to replace*, and drops entirely when no AI step is recorded. **Next:** decide with the owner whether the plain line replaces the per-process sentences or sits above them, then make the generator emit the chosen wording and keep the existing 125 packages untouched.
- [ ] **A metadata file that will not parse is still skipped without a word** — the versions reader in `electron/server/routes/scripts.ts` reads each matching file with `.catch(() => null)` (around `:2040`) and `continue`s past a file whose JSON does not parse, so a corrupt or half-written record simply disappears from the list. The same swallow-everything shape in the override readers is fixed (`d15be2168`, guard measured at 50 concurrent reads: 48 empty before, 0 after) but has no dedicated test. **Next:** log the skip with the file name, add the test, and give the reader the same role-guard the override readers got.
- [ ] **Busy-state and long-run memory are unmeasured** — idle is proven flat over 600 s (317 MB → 160 MB), but no whole-job-cycle or long-run figure exists, and the owner's ceiling names three states. **Next:** measure both on a quiet machine with a throwaway data dir and real jobs, and record them on the next receipt.
- [ ] **Sparkle's own swap and relaunch is unproven on this Mac** — proven are the feed URL, the key, the framework in the shipped bundle, the hold taken before the fetch, and the live appcast correctly judged older. Not proven: Sparkle replacing the app and relaunching, because its relauncher activates a window on the live data folder. **Next:** prove the swap on the test Mac, where a visible relaunch is acceptable.
- [ ] **The shim's hold-request ceiling is shorter than the route's settle window** — the shim waits 5 s per request while the hold route settles up to 20 s, so on slowly settling work a launch can report a refusal where the route would have answered safe. **Next:** the shared shim's owner decides the window; raise it or record why it stays.
- [ ] **The 10-second release grace is a recorded shortcut** — if a feed check takes longer than 10 s with an update waiting, the hold is released before Sparkle reports it. **Next:** remove it once the shared shim releases its own hold on a finished background cycle.
- [ ] **`/youtube/preview` still serves a blank description, but it no longer does so silently** — an empty description now logs which case it is and returns a warning naming the fix (no metadata generated vs. saved metadata with no description, `electron/server/routes/youtube-upload-center.ts:3129-3145`, shipped 1.4.414/1.4.420). What is unproven is the original Production report: a package that *has* text still returning blank. **Next:** reproduce with one of the affected packages on Production; every miss since then has been a package that really had no description.
- [ ] **Install acceptance on the intended machine** — 1.4.422 is published and its bytes launch, but no Launcher automatic install has been read back on the Production Mac. **Next:** record the installed-version readback the next time it installs itself.
