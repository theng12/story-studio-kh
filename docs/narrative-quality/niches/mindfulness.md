# Mindfulness

**Resolved perspective:** Second-person guided practice.

**Quality contract:** Direct, calm, and procedural. Repetition is intentional when it supports breath or body awareness.

**Opening and outline:** State the practice and its immediate setting plainly, then guide breath/body attention in a timed progression and return gently to day or sleep.

**Avoid:** “Imagine this,” generic inspiration, therapy claims, mystical certainty, applause, and creator sign-off chatter.
