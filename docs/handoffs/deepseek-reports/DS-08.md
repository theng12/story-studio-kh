## Reproduction and root cause
### F-11 — four hand-maintained label maps had drifted
Counting the keys of each map at the base against the live 33-type `JOB_TYPES` union:
- `composables/useJobs.ts`: **6 live types missing** (`youtube_thumbnail_refresh`, `scene_clip_generate`, `expression_markup`, `image_pool_generate`, `music_generate`, `music_video`).
- `composables/useNotifications.ts`: **7 missing** (the same six plus `composition_generate`).
- `components/EpisodeSelector.vue`: **20 of 33 missing** (raw slugs in the dropdown).
- `pages/projects/[slug]/jobs.vue`: 0 missing (complete, but still a fourth copy).
A missing entry rendered the raw internal id. Evidence: the key-diff script run against `git show HEAD:<file>` (numbers above); the shared map is now the one authority.

### Q-06 — Retry offered on rows the backend always refuses
`routes/jobs.ts:retryAdmissionError` always 409s `image_prompts` with a non-`thumbnails` mode and `images` with a non-`thumbs` mode. The page's `canRetryJob` did not check the mode, and `failedJobsForRetryAll` passed every failed row to the triage, so both offered a Retry that could only fail. Added `retryAdmissionAllowed` (the frontend mirror, truthiness-matched to the backend guard) to both paths.

### Q-07 — two permanently empty filter tabs
`filterTabs` hard-coded `scene_images` and `scene_images_batch`, neither of which is in `JOB_TYPES` any more. The dynamic loop below the list already adds a tab for any historical row of an unknown type, so the hard-coded entries only produced two tabs that could never show anything. Removed.

### Q-08 — filtered-empty read as "no jobs yet"
`emptyTitle` considered the type filter and hidden jobs, but not `statusFilter` or `failureBatchFilter`, so a nonempty history filtered to zero said "No jobs yet". Extracted the decision to the pure `jobsEmptyState`, which now returns "No matching jobs" when a filter hides a nonempty set.

### Q-09 — `finish-missing-images` on an `_app_` URL
`jobQueuePath` routes `_app_` rows to `/jobs/all/:id`, which does not serve `finish-missing-images`. **Not reproduced:** the only callers are gated on `continuity_render`, and the only `_app_` job types are the B-Roll pool jobs (`broll_normalize`, pool assembly) — no `_app_` `continuity_render` or `scene_plan_run` can exist, so the URL is unreachable today. Left unchanged per the "do not change dormant code" rule; recorded as a latent symmetry gap.

### Q-10 — subtitle Retry tooltip named a control that is not rendered
`REPAIR_ENDPOINTS` contains only `audio` and `thumb_images`, so `jobCanBeRepaired` is false for `subtitles_transcribe` and no Repair button renders. The subtitle tooltip still said "Repair first retrieves saved GenStudio work for free." Replaced with the real Retry behaviour.

### Test-harness regression found and fixed
`jobsRetryAllManualFinish.test.ts` compiles `jobs.vue` against a hand-written stub preamble listing every free identifier the page uses. Removing the page's local label functions made `jobTypeLabel`, `jobDisplayLabel`, `jobsEmptyState` and `retryAdmissionAllowed` unresolved there; the resulting computed error left the isolation child alive, which hung the whole frontend lane. The preamble now binds the four real functions through `globalThis`, and the file passes 11/11 and exits cleanly.
