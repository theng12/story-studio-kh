## Reproduction and root cause
- **E-01 — Scene Review.** `loadReview`'s catch was `if (e?.__slugRace) return` and otherwise swallowed the failure, while the template rendered "No scene plan yet" whenever `!stats && !plan && !loading`. A failed read therefore told the user to redo work that may exist, with no error and no retry.
- **E-02 — Research.** `loadSources` caught the failure, showed a toast, and left `genStudioSource.configured` at its default `false`. `runDisabledReason` then said "GenStudio API not configured — Settings → This Mac", sending the user to re-enter a key that may already be valid.
- **E-06 — Pipeline.** The accepted-ideas list comes from `useEpisodes`, whose `error` ref was only toasted. On a failed read `episodes` stayed empty, so the template rendered "No accepted ideas yet. Go to Ideas Generator and accept some first."
